AjanDB

API Keys

Stored only in this browser's local storage — never sent anywhere except with your own requests to this page's backend, and never saved server-side or in the database. None of these are the same as a claude.ai/ChatGPT Plus subscription or an Azure account login; all are separate, billed-by-usage credentials from that provider's own developer console (console.anthropic.com / platform.openai.com / Azure Portal's Speech resource). Leave blank to fall back to whatever the backend's own environment has configured.

Data Store

Accepts .pdf, .docx, .txt, .md. PDFs are digitised (text extraction + OCR/vision + handwriting detection) and stored as markdown.

Higher DPI sends a sharper page image to the model - worth raising for small or handwritten text, at the cost of a larger image per page (slower, more tokens).

The vision engine and category auto-suggestion need an API key — set one in the API Keys panel above, or leave it to the backend's own environment.
