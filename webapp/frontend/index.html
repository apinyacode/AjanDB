AjanDB

API Keys

Stored only in this browser's local storage — never sent anywhere except with your own requests to this page's backend, and never saved server-side or in the database. Neither key is the same as a claude.ai or ChatGPT Plus subscription; both are separate, billed-by-usage credentials from that provider's own developer console (console.anthropic.com / platform.openai.com). Leave both blank to fall back to whatever the backend's own environment has configured.

Data Store

Accepts .pdf, .docx, .txt, .md. PDFs are digitised (text extraction + OCR/vision + handwriting detection) and stored as markdown.

The vision engine and category auto-suggestion need an API key — set one in the API Keys panel above, or leave it to the backend's own environment.
